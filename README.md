
# Прозрачная вакансия

Прототип анализирует вакансии Калининградской области из открытого API «Работа в России» и формирует JSON-отчёт о понятности условий труда.

## Стек
- Python 3.10+
- requests
- Ollama + Qwen 2.5 3B (локально, без API-ключа)

## Что проверяется
Название должности, обязанности, требования, оплата, график, место работы и тип занятости. Сначала выполняются проверки заполненности и простые правила, затем Ollama анализирует неоднозначные формулировки. Структурированные поля учитываются наряду с текстом вакансии.

## Установка на Windows
1. Установить Python 3.10 или новее.
2. Установить Ollama: https://ollama.com/download
3. Открыть PowerShell в папке проекта.
4. Создать окружение и установить зависимости:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

5. Скачать модель и проверить её:

```powershell
ollama pull qwen2.5:3b
ollama run qwen2.5:3b
```

В отдельном терминале Ollama должен быть доступен по адресу `http://localhost:11434`.

## Запуск
Рабочий режим (API региона 39, по умолчанию до 200 вакансий):

```powershell
python main.py --api
```

Проверочный режим на локальном JSON:

```powershell
python main.py --input sample_input.json
```

Быстрая проверка без ИИ:

```powershell
python main.py --input sample_input.json --no-ai
```

Переопределить лимит:

```powershell
python main.py --api --limit 200
```

Настройки URL, расписания запуска, лимита, модели и путей находятся в `config.json`. По умолчанию запрашиваются две страницы по 100 вакансий. API использует параметры `limit` и `offset`; максимум 100 записей на страницу.

## Формат отчёта
`reports/report.json`:

- `vacancies` — массив обработанных вакансий;
- `id` — ID вакансии из источника;
- `url` — ссылка на карточку, если присутствует;
- `issues` — массив замечаний; если проблем не найдено, массив пустой;
- каждое замечание содержит `topic`, `source_field`, `quote`, `problem`, `recommendation`.

Для пропуска `quote` пустая строка. Для противоречий в цитате/описании замечания должны быть приведены оба исходных значения.

## Автоматический запуск в Windows
Для демонстрации предусмотрен ручной запуск. Для расписания создайте задачу в «Планировщике заданий Windows»:
- Триггер: ежедневно, например 09:00.
- Программа: полный путь к `.venv\\Scripts\\python.exe`.
- Аргументы: полный путь к `main.py --api`.
- Рабочая папка: корневая папка проекта.

## Надёжность
- При ошибке API программа не перезаписывает предыдущий успешный отчёт.
- Повторные вакансии с одинаковым ID не дублируются в одном отчёте.
- Локальный режим не обращается к API.
- Ошибка Ollama логируется; сохраняются результаты проверок правилами.

## Файлы проекта
- `main.py` — точка входа;
- `src/api.py` — получение данных и пагинация;
- `src/analyzer.py` — проверки и объединение замечаний;
- `src/ollama_client.py` — локальный вызов Qwen;
- `src/report.py` — чтение JSON и сохранение отчёта;
- `config.json` — настройки.

## Ограничения MVP
Качество анализа зависит от полноты полей API и ответов локальной модели. Замечания ИИ являются рекомендациями редактору, а не юридической оценкой вакансии.
